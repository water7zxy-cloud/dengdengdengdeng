# 页面声音

`soundtrack.ts` 使用浏览器 Web Audio 在本地合成背景音乐和短音效，无需在线音乐服务或额外依赖。

- 封面：慢速、柔和的正弦旋律与和弦；正文结束和灯泡落下后继续播放，进入选角再切换音乐。
- 选角：轻快的旋律与低音，切换时淡入淡出。
- 文字揭示：每字约 130 毫秒；使用金属敲击与稍后的回键双段噪声，去除原有有音高的“噔噔”音符。
- 灯泡落下：在正文结束时播放约 0.62 秒的扫频“咻”声，与下落动作同时开始。
- 点击灯泡：短按键声与 `public/assets/welcome/等灯音频-clean.wav` 同时播放。录音在切到选角后继续播完，选角页开始轻快背景音乐。
- 离开选角进入后续游戏阶段时，背景音乐淡出；网页隐藏时停止背景乐调度，返回时恢复。

音乐、打字和按键的音量分别在 `audioLevels` 中配置。旋律和节拍在本文件中分别定义；用户录音的路径在 `../welcome/config.ts` 中配置。

首次访问尝试自动播放，图片加载后正文立即开始打字，不等待音频解锁。若浏览器拦截声音，点击页面或按键后启用音频；不补播已经结束的打字声或下落声。不添加额外的封面按钮。

背景音乐增益由 0.15 提高至 1.2（约 +18 dB）；打字声、按钮声与下落声分别配置。录音原文件保留，网页播放轻度频谱降噪、频段清理、音量整理后的净化版。生成脚本为 `tools/prepare-welcome-audio.mjs`，可在 macOS 上从原 M4A 重新生成 WAV。未试听，实际音质和主观响度由设计者验收。
