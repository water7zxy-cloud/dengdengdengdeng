# 封面当前参数

- 正文字形每 80 毫秒揭示一次；机械打字声每 130 毫秒一次。两者节奏独立，共用同一音频输出时钟，在每行开始同时触发，打字结束后停止敲击，背景音乐继续。
- 音频按时间表提前调度；若浏览器未解锁有声播放，则等待音频启用后再启动正文。网站无法强行覆盖浏览器自动播放策略。
- 灯泡文字保留当前宋体字体与字形设置，只提高至 600 字重，并增加轻微描边加粗；不替换字体。
- 点击录音使用已保存的 `public/assets/welcome/等灯音频-cute.wav`，包含净化与轻微可爱化处理；播放音量设为 40%。原始 M4A 与净化版 WAV 保留。
- 主观音量与同步听感尚未测试，由设计者试听验收。
