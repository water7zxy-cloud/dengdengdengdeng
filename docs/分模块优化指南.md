# 等灯 dengdeng：分模块优化指南

本次拆分保留现有素材、布局和规则，把页面、样式与游戏状态分别管理。未执行测试；拆分后的运行与交互由设计者验收。

## 模块入口

| 模块 | 主要文件 | 在这里优化什么 |
| --- | --- | --- |
| 封面 | `src/modules/welcome/Welcome.tsx`、`welcome.css`、`config.ts` | 背景、logo、按钮位置、文案、欢迎语音 |
| 角色选择 | `src/modules/selection/RoleSelection.tsx`、`selection.css` | 六个角色的排列、选中效果、角色信息 |
| 开局 | `src/modules/setup/FirstRoll.tsx`、`LanternStart.tsx`、`setup.css` | 先手掷骰、留灯人起点选择 |
| 游戏画面 | `src/modules/tabletop/Tabletop.tsx`、`tabletop.css` | 地图显示、棋子、分数、回合操作、爪印 |
| 骰子外观与点数显示 | `src/modules/dice/Die.tsx`、`dice.css` | 骰子造型、尺寸、点数样式 |
| 骰子动画 | `src/modules/dice/DiceOverlay.tsx`、`config.ts` | 屏幕中央出现、旋转、退场 |
| 骰子结果生成 | `src/modules/dice/config.ts` 的 `randomDie` | 当前为 1–6 的随机整数；与展示组件分离 |
| 卡牌 | `src/modules/cards/CardDialog.tsx`、`cards.css` | 飞出、翻面、圆角、答题操作 |
| 结算 | `src/modules/results/Finale.tsx`、`results.css` | 排名、分数、重新开始 |
| 音频 | `src/modules/audio/soundtrack.ts` | 封面与选角音乐、打字声、按钮音、音量 |

`src/App.tsx` 负责根据当前阶段选择页面。`src/game/useGame.ts` 管理玩家、轮次、掷骰和卡牌结算；组件通过参数接收数据与操作。更改画面时，通常不需要修改游戏状态文件。

地图坐标和路径在 `src/game/board.ts`；人物、卡牌内容与资源路径在 `src/game/content.ts`；规则在 `src/game/rules.ts`；共享类型在 `src/game/types.ts`。全局排版与通用按钮样式在 `src/styles.css`。所有运行素材仍放在 `public/assets/`。

## 建议的优化顺序

1. 封面：提交背景设计稿和按钮位置；确定完整显示还是铺满裁边，再替换封面组件和样式。
2. 游戏画面：确定地图显示方式，逐格校准棋子落点，再安排分数、回合操作的位置。
3. 骰子：先确定外观方案，再确定投掷动作、时长、最终点数显示与棋子开始移动的时机。
4. 卡牌：校准对应牌堆的起点，完善背面、翻面、结算后回堆的动作。
5. 选角与结算：最后统一按钮、卡片和信息布局。

当前没有新增骰子外观选择器；骰子外观、动画和结果生成已分别提取，后续可独立优化。当前棋子运动、随机抽牌和流程仍沿用拆分前的实现；模块拆分不代表这些待优化项目已经完成。

## Photoshop 封面交付

- 推荐画布：3840 × 2160 像素，16:9，RGB，sRGB，保留 PSD。
- 导出 PNG；若含透明背景，保留透明度。照片较多的背景也可另交高质量 JPG。
- 1920 × 1080 是显示尺寸参考；在高分屏以约 1920 × 1080 的网页尺寸展示时，3840 × 2160 素材提供两倍像素密度。
- PPI 不决定网页清晰度。把 72 ppi 改成 300 ppi、但不增加有效像素，不会使网页变清晰。
- 从原始矢量、文字图层和高分辨率图片制作；将低分辨率成品直接放大至 4K 不会恢复丢失细节。
- 重要内容建议距四边约 240 像素；它是构图建议，无法保证所有屏幕在铺满裁边模式下都不裁切。
- 若背景已包含 logo，网页封面不再叠放 logo；可点击按钮由网页叠加。请同时标明按钮在设计稿上的位置与大小。
- 资产示例位置：`public/assets/welcome/cover.png`；交付后由封面模块接入。
